# 🌳 기억력 쑥쑥

어르신(70·80대)을 위한 매일 기억력 훈련 놀이 앱입니다.

## 실행

```
npm install
npm start          # 앱 실행
npm run dist       # Windows 설치 파일(.exe) 만들기 → dist/ 폴더
```

## 휴대폰에 설치하기

`app/` 폴더는 그대로 웹앱(PWA)으로도 동작합니다.
`app/` 폴더를 GitHub Pages, Netlify 같은 HTTPS 주소에 올린 뒤,
휴대폰 크롬(또는 사파리)으로 열고 **"홈 화면에 추가"**를 누르면 앱처럼 설치됩니다.
한 번 열면 인터넷 없이도 실행됩니다.

## 구성

| 파일 | 내용 |
|---|---|
| `main.js` | Electron 창 |
| `app/app.js` | 화면, 놀이 6종, 엽전·출석·감나무 |
| `app/data.js` | 추억의 물건, 이야기, 노래·속담·민요 문제 (여기에 문제를 추가하면 됩니다) |
| `app/style.css` | 큰 글씨, 한지·단청 색 디자인 |

기록은 기기 안(localStorage)에만 저장됩니다.
